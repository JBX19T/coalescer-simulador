# COALESCER · simulador 3D

Jogo em primeira pessoa que ilustra a ideia do projecto de Oscilações e Ondas (Engenharia Petrolífera, ISPTEC): como um campo ultrassónico estacionário poderia juntar gotículas de óleo num vaso separador.

**É uma simulação de uma hipótese. O projecto ainda não tem resultados experimentais e nada aqui é medição.**

Controlos: comando PS4 (ou teclado e rato). Carrega em **K** no título para configurar os botões, **G** para a apresentação guiada, **L** para PT/EN. Funciona melhor no Chrome ou no Edge.
